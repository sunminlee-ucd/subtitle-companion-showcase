## Walkthrough format

- [MP4](assets/subtitle-companion-public-walkthrough.mp4): a silent, 20-second navigation montage; each of the five browser captures is shown for four seconds.
- [GIF preview](assets/subtitle-companion-public-walkthrough.gif): an animated preview generated from the same MP4.
- The MP4 uses H.264, 1280 × 580 pixels, and 12 frames per second. Screens are scaled proportionally and padded to one frame size.
- The GIF uses a smaller image size and reduced color palette for GitHub README display.

This is an assembled walkthrough, not a continuous screen recording. It demonstrates the public entry and installation experience. Authenticated library use, live translation, browser subtitle synchronization, and Android overlay playback require separate demonstrations.

## Reproducibility and maintenance

The screens can be revisited through the public About, Learn, How it works, Download, and Customer portal links. Page content and package versions may change after the capture date.

The media addition does not modify the running service. It does not certify overall application health, paid translation behavior, or device compatibility. The source-derived cue-core example and tests are available separately in [examples](examples/README.md).
